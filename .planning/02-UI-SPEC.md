## Design System

Inherits entirely from `01-UI-SPEC.md`:

- Font: geist

---

## Layout Architecture

| Component | Constraints |
|-----------|-------------|
| Shell | App Sidebar (Left) + Main Content Area + Header |
| Header | Sticky top, includes current page title/breadcrumbs and user logout |
| Sidebar | shadcn `Sidebar` component. Dark theme (slate-900) or light (slate-50). |
| Page Container | `max-w-7xl mx-auto p-6 space-y-6` |

---

## Interaction Patterns

| Action | Pattern |
|--------|---------|
| Create Record | Slide-out `Sheet` (right side) or `Dialog` modal |
| Edit Record | Same as Create (reusing the form component) |
| Delete Record | `AlertDialog` requiring confirmation (destructive action) |
| Data Display | `Table` with pagination and search/filter inputs above |
| Enrollment | Multi-select dropdown or dual-list selection within a `Sheet` |
