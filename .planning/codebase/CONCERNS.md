# Concerns

## Technical Debt & Issues

1. **Multiple Supabase Clients**:
   - There are redundant Supabase client files (`utils/supabase/client.ts`, `utils/supabase/supabase.ts`, and `src/lib/client.ts` generated by shadcn). These need consolidation to prevent conflicting configurations and initialization errors.

2. **Environment Variable Parity**:
   - The `.env` and `.env.local` files must be kept in strict sync.
   - The app currently relies on `VITE_SUPABASE_PUBLISHABLE_KEY` based on Supabase dashboard setup, but previous iterations used `VITE_SUPABASE_ANON_KEY`.

3. **Face Engine Process Management**:
   - The Python Face Engine runs as a separate local process. Starting/stopping this service in tandem with the Vite dev server currently requires manual coordination.
   - Cross-Origin Resource Sharing (CORS) or proxying between Vite and the Flask API must be carefully managed.

4. **Theme Provider Context**:
   - Certain Shadcn components (like `sonner`) expect a `next-themes` ThemeProvider which is not present, leading to null pointer errors if not manually patched to a hardcoded theme.
