# Structure

Key directories and their purposes:

- `src/` - Main application source code (React).
  - `src/app/` - Core application logic.
    - `src/app/components/` - Reusable UI components.
      - `src/app/components/layout/` - Layout components (e.g., `DashboardLayout.tsx`).
      - `src/app/components/ui/` - Shadcn UI components.
    - `src/app/routes.tsx` - Application routing definition.
    - `src/app/App.tsx` - Root React component.
  - `src/lib/` - Shared libraries and generated shadcn utilities.
  - `src/main.tsx` - Application entry point.
- `utils/` - Shared utilities.
  - `utils/supabase/` - Supabase client configurations and autogenerated info.
- `face_engine/` - Python-based face recognition module (Flask + OpenCV).
- `supabase/` - Supabase specific configuration (migrations, schema).
- `dist/` - Production build output (generated by Vite).
- `.planning/` - GSD planning artifacts and codebase mapping.
